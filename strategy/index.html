📐 전략 1 — 10주선/종가 비율

상승장(종가 > 10주선)에서 10주이동평균선 ÷ 종가 비율로 과열 구간을 판단합니다. 비율이 낮을수록 종가가 10주선에서 멀리 벌어진 것 = 과열.

≤80% 10주선 가까이. 상승 추세 정상 구간. 재매수 관점
≤70% 반환점. 상승 모멘텀 확인 필요. MDD 커지기 시작. 기세 확인
≤60% 과열 구간. 평균 4주후 마이너스, 승률 25%. 매도

⚡ 전략 2 — 5주선 이탈 (30%+ 상승 후)

5주선을 올라탄 뒤 30% 이상 상승한 종목이 5주선 아래로 종가가 내려오면 이탈로 판정합니다. 10주선까지 하회하면 라이드 종료.

1차 이탈 첫 이탈. 반등 가능성 있으나 경고등. 평균 4주후 -4.2%. 분할매도 1차
2차 이탈 재차 이탈. 기간/가격 조정 없이 간다면 주도주가 아닐 수 있음. 매도 고려

🔧 사용법

자동 갱신: 매주 금요일 장 마감 후(21:05) 전 종목 스캔 → 텔레그램 알림 + 이 페이지 갱신.
텔레그램: 신규 시그널 + 구간별 전 종목 + 관심종목 현황이 봇 DM으로만 발송됩니다 (채널 미발송).
관심종목: 현재 대한항공·현대건설. 변경 시 scripts/fetch_ma_signal.py의 WATCHLIST 수정.
데이터: KIS Open API 주봉 71주치 → 5WMA/10WMA 계산. Oracle MA_SIGNALS 테이블에 시그널 이력 저장.
