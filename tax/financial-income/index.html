📘 사용설명서 — 이 도구 읽는 법

1. 이 도구의 목적

연간 금융소득(이자+배당)이 2,000만원을 넘으면 초과분이 근로소득 등에 합산되어 종합과세됩니다. 이 도구는 채권 이자·주식 배당·예금 이자를 합산해서 한도까지 얼마나 여유가 있는지 추적하고, 넘어갔을 때 어떤 세율 구간에 진입하는지 경고합니다.

2. 공통 조건 — 환율 3개의 의미

  • 상반기 환율: 1~6월에 받는 이자를 원화로 환산할 때 쓰는 환율. 아직 안 받았으면 예상치, 받았으면 당시 환율.
  • 하반기 환율: 7~12월 이자 환산용. 같은 원리.
  • 만기 환율: 만기 시 원금 상환 때 적용할 예상 환율. 비과세 환차익 계산에만 사용. 금종세 합산과 무관.

기존 과세표준: 본인의 근로소득·사업소득에서 소득공제를 뺀 금액. 금융소득이 2,000만 넘으면 초과분이 여기에 얹히므로, 이미 8,800만 이상인 고소득자는 초과분 전액이 35%+로 갑니다.

안전 버퍼: 예상 못한 이자·배당 발생 대비 마진. 여유구간에서 이만큼 추가로 빼서 안전하게 관리.

3. 게이지와 경고 색상

🟢 초록 (안전): 한도 80% 이하. 여유 있음.
🟡 노랑 (주의): 80~100%. 추가 이자 발생하면 금종세 진입 가능.
🟠 주황 (금종세 대상): 2,000만 초과, 합산 과표 5,000만 이하. 15% 구간이라 추가 부담 제한적.
🔴 빨강 (24% 구간): 합산 과표 5,000~8,800만. 세율 9%p 점프. 체감 시작.
⬛ 진빨강 (35%+ 직행): 합산 과표 8,800만 초과. 수익의 약 40%가 세금. 법인 전환 검토.

4. 미국채 탭 — 메인 테이블 읽는 법

  • 액면($): 채권 1장당 액면가. 미국채 보통 $1,000.
  • 매수단가($): 실제 매수 가격. 할인채면 액면보다 낮음 (예: $920).
  • 수량: 매수 장수.
  • 매수환율: 매수 시점 환율. 채권마다 다를 수 있음.
  • 투자금(₩): 매수단가 × 수량 × 매수환율. 실제 투입 원화.
  • 이율%: 표면이율(쿠폰). 연간 기준.
  • 연이자(₩): 상반기+하반기 이자의 원화 합계. 확정값이 있으면 확정값 우선.

5. 반기별 이자 상세표 — 핵심 관리 도구

예상값 = 반기이자($) × 해당 반기 환율. 자동 계산.
확정값 = 실제 수령 후 세전 원화 금액 직접 입력.

확정 입력하면 → 예상값 흐려짐 → 확정값이 금종세 합산에 반영.
비어있으면 → 예상값 사용.

상태 표시: 🟢전부 확정 / 🟢🟡일부 확정 / 🟡전부 예상

반기마다 이자를 받을 때 증권사 입금내역(세전)을 확정란에 입력하면 연말에 정확한 금종세 합산이 가능합니다.

6. 만기 시 수령·비과세 환차익

  • 할인차익($): 액면 − 매수단가. 할인 매수 시 양수 → 과세 (보유기간이자로 금융소득).
  • 비과세 환차익(₩): 매수원금($) × (만기환율 − 매수환율). 개인 비과세 — 미국채 투자의 핵심 매력. 법인은 과세.
  • 만기 총 수익(₩): 만기수령(₩) − 투자금(₩). 이자·환차익·할인차익 전부 포함.

7. 과세표준 구간 카드 읽는 법

파란색 = 현재 기존 소득이 속한 구간.
빨간색 = 금융소득 합산으로 새로 진입하게 된 구간.
둘 다 없으면 = 금종세 미해당 (2,000만 이하).

핵심: 과세표준은 금융소득만이 아니라 기존 소득 + 2,000만 초과 금융소득의 합계입니다. 연봉이 높을수록 금종세 진입 시 더 높은 세율로 직행합니다.

8. 주식 배당 / 예금·기타 탭

국내주식은 원화 기준. 주당 배당금 × 주수 = 연간 배당. 예금은 예치금 × 이율 × (기간/12) = 이자. 모두 세전 기준으로 금종세에 합산됩니다.

9. 자동저장 & 슬롯

자동저장: 입력할 때마다 자동으로 브라우저에 저장됩니다. 새로고침해도 데이터가 유지됩니다. (같은 브라우저·같은 기기 한정)

슬롯 저장: 상단 슬롯은 이름 붙여 저장하는 기능. 시나리오별로 다른 세팅을 비교하고 싶을 때 사용. 슬롯에서 불러오기하면 자동저장 데이터도 덮어씁니다.

⚠️ 금종세 기준: 연간 금융소득 2,000만원 초과 시 종합과세. 이하는 15.4% 분리과세 종결. 미국채: 미국 원천세 0%, 국내 15.4%. 환차익은 개인 비과세(법인 과세). 실제 신고는 세무사 상담 권장.
