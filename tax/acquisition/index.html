📘 사용 설명서

① 입력값 설명

  • 부동산 구분 주택/농지/농지외 토지/상가·건물 중 선택. 세율 구조가 완전히 다름.
  • 취득가액 매매가 또는 시가표준액. 증여·상속도 시가 기준.
  • 전용면적 주택 매수 시 85㎡ 초과면 농어촌특별세 가산. 토지·상가는 무관.
  • 주택수·조정지역 다주택 중과 판정용. 1주택은 1~3% 선형 / 2주택 조정시 8% / 3주택↑ 또는 법인 12%.
  • 취득 유형 매매/증여(3.5%)/상속(2.8%)/신축(원시취득). 증여·상속은 별도 세율표.

② 세율 (주택 매매)

  • 6억 이하: 1%
  • 6~9억: 1~3% (선형 증가)
  • 9억 초과: 3%
  • 다주택 중과: 2주택 조정 8% / 3주택+ 또는 법인 12%

③ 오피스텔 (용도별)

  • 업무용: 일반건물 4.6%(취득세4%+교육세0.4%+농특세0.2%) 단일. 주택 수에 포함 안 됨. 부가세 환급 가능(일반임대사업자).
  • 주거용: 주택 세율(1~12%) 적용. 2020.8.12 이후 취득분은 주택 수에 포함(다른 주택 취득 시 중과 영향). 단 시가표준액 1억 이하는 주택 수 제외. 85㎡ 이하 농특세 면제.
  • 실제 사용 용도로 판정(등기부상 용도 아님). 경계 사례는 세무 전문가 상담 권장.

④ 부가세금

  • 지방교육세: 주택 일반 = 취득세×10% / 농지 0.2% / 농지외·상가·업무용오피스텔 0.4% / 증여 0.3% / 상속 0.16%
  • 농어촌특별세: 주택·주거용오피스텔 85㎡ 초과 0.2~1% (85㎡ 이하 면제) / 농지 면제 / 농지외·상가·업무용오피스텔 0.2%
⚠ 주의: 일시적 2주택, 생애최초 감면, 신혼부부 감면 등 특례는 미반영. 실제 신고시 확인 필요.
