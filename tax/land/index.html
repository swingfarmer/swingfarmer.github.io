🌳 양도소득세 계산기 (토지)

토지(농지·임야·대지 등) 매도 시 양도세. 사업용/비사업용 구분, 자경농지 감면 옵션. (2026년 5월 기준)

📥 입력값

① 거래 정보
② 보유 기간
③ 토지 상태

📘 사용 설명서

① 입력값 설명

  • 양도/취득가액 매도가·매입가 (실거래).
  • 필요경비 취득세·중개수수료·개발부담금·측량비 등.
  • 보유기간 취득일~양도일 (정수).
  • 토지 유형
    • 사업용: 농업·축산업·임업에 직접 사용 / 본인 사업장 / 별장 등 본인용
    • 비사업용: 지목과 실제 사용이 다른 토지 (투기 목적 등) → 10%p 중과
  • 지목 구분 농지(전·답·과수원) vs 농지외(대지·잡종지·임야 등). 자경농지 감면 판정용.
  • 자경농지 8년+ 본인이 8년 이상 직접 경작한 농지 양도 시 1억 한도 감면.

② 계산 로직

  • 장기보유특별공제: 보유 3년 이상부터 매년 2%, 최대 30% (사업용·비사업용 동일).
  • 자경농지 감면: 8년 이상 자경 시 1억 한도. 1년 1억 한도, 5년 누적 2억.
  • 기본 누진세율: 6%~45% 8단계.
  • 비사업용 토지 중과: 기본세율 + 10%p.
  • 단기보유 세율: 1년 미만 50% / 1~2년 40%. 누진+가산과 비교해서 큰 값 적용.
  • 지방소득세: 양도세의 10%.
⚠ 주의: 토지 양도세는 지목·실제용도·자경요건 판정이 까다로움. 농지 양도 시 자경 입증(농약·종자·농기계 영수증)이 필요. 비사업용 판정 분쟁 많음. 실제 신고는 세무사 상담 권장.
