📖 시그널 설명

이동평균선

📈 5주선 돌파
주봉 기준 5주 이동평균선을 종가가 상향 돌파. 직전 주 종가 < 직전 5주선 → 이번 주 종가 ≥ 이번 5주선.
📈 20일선 돌파
일봉 20일 이동평균선을 종가가 상향 돌파. 전일 종가 < 전일 MA20 → 당일 종가 ≥ 당일 MA20.
📈 10주선 돌파
주봉 기준 10주 이동평균선을 종가가 상향 돌파. 5주선과 동일 방식, 10주 SMA 사용.

크로스 / 배열

✨ 골든크로스
5일선이 20일선을 상향 돌파 (MA5 > MA20). 단기 추세 전환 시그널.
💀 데드크로스
5일선이 20일선을 하향 돌파 (MA5 < MA20). 하락 추세 전환 시그널.
🔥 정배열
MA5 > MA20 > MA60. 단기·중기·장기 이평선이 순서대로 정렬된 강세 상태.

볼린저밴드

🔺 볼밴상단 종가
종가가 볼린저밴드 상단(20일, 2σ)을 돌파. 강한 상승 모멘텀.
⚡ 볼밴상단 장중
장중 고가가 볼밴 상단을 터치했으나 종가는 미돌파. 저항 테스트.

모멘텀 / 거래량

🚀 3일양봉 10%↑
최근 3거래일 연속 양봉 + 합계 수익률 10% 이상.
💥 거래량 폭발
당일 거래량 ≥ 20일 평균 × 2배.
📊 거래량 돌파
5일 평균 거래량 > 100일 평균 거래량. 거래 활성화 구간.

가격 / 기술적 지표

🏔 52주 신고가
장중 고가가 최근 52주(보유 데이터 범위) 최고가와 동일.
🕳 52주 신저가
장중 저가가 최근 52주 최저가와 동일.
🟢 RSI 과매도
RSI(14) ≤ 30. 과도한 매도 → 반등 가능성.
🔴 RSI 과매수
RSI(14) ≥ 70. 과도한 매수 → 조정 가능성.
⚙ MACD 골든
MACD선이 시그널선을 상향 돌파 (EMA12-EMA26 > Signal9).

수급 (외인·기관)

🏦 외인 매수/매도 T15
당일 외국인 순매수금액 상위/하위 15종목.
🏛 기관 매수/매도 T15
당일 기관 순매수금액 상위/하위 15종목.
📊 외인 연속매수
외국인이 3거래일 이상 연속 순매수한 종목. 수급 이력이 충분히 쌓여야 집계됨 (최소 3~5일 이상 데이터 필요).
📊 기관 연속매수
기관이 3거래일 이상 연속 순매수한 종목.
🟢 프매도+외매수
최근 3거래일 연속으로 프로그램 순매도 + 외인 순매수. 외인이 프로그램 매도 물량을 흡수하며 추가 매수하는 강세 패턴.
🔴 프매수+외매도
최근 3거래일 연속으로 프로그램 순매수 + 외인 순매도. 약세 패턴.
※ 수급 시그널(연속매수, 프매도+외매수)은 수급 이력이 3거래일 이상 쌓여야 작동합니다.
※ 이동평균선: 5주선·10주선은 주봉(주간 마지막 거래일 종가) 기준, 20일선은 일봉 기준입니다.
※ 데이터 소스: KIS Open API · 평일 장 마감 후 자동 수집.
