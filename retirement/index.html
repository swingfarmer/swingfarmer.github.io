💰 은퇴 설계

은퇴 시점과 필요 자금을 계산하는 도구 모음입니다. 두 계산기는 접근 방식이 다르니, 목적에 맞게 골라 쓰세요.

💡 어떤 걸 쓸까? — 현재 자산·수입·지출로 "언제 은퇴 가능한지" 보려면 경제적자유 계산기, 목표 생활비로 "얼마가 필요한지" 역산하려면 파이어족 계산기를 쓰세요.
📈
경제적자유 계산기
현재 자산·수입·지출·연금을 입력하면 은퇴 시점과 100세까지의 자산 추이를 자동 계산. "언제 은퇴할 수 있나"를 봅니다.
사용 가능
🎯
파이어족 계산기
월 소비액과 사망 시 남길 금액을 입력하면 은퇴 시점에 얼마가 필요한지 역산. "얼마면 은퇴되나"를 봅니다.
