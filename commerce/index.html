🎯 목적별 추천 사이트

① 창업·점포 입지 분석

  • 1순위: 소상공인 상권정보시스템 → 업종별 평균 매출·경쟁점 확인
  • 2순위: 서울 우리마을가게 (서울만) → 분기별 매출 추이
  • 3순위: KT 잘나가게 → 시간대별 유동 패턴
  • 참고: 같은 위치라도 업종 따라 결과 달라짐. 3개 사이트 모두 보고 종합 판단.

② 상가/사무실 매수 분석

  • 1순위: 디스코 → 실거래가, 임대료, 등기부
  • 2순위: 소상공인 상권정보 → 주변 상권 매출 수준
  • 3순위: 카카오맵 → 주변 시설·교통 체크
  • 참고: 본 사이트의 상가 수익률 분석기로 매물 분석 → 외부 사이트로 입지 검증.

③ 아파트 매수/전세 분석

  • 1순위: 호갱노노 → 시세·학군·실거주 후기
  • 2순위: 국토부 실거래가 → 정확한 거래 이력
  • 3순위: 서울 도시데이터 → 동네 인구 흐름 (인구 유입 vs 유출)

④ 재개발·재건축 분석

  • 1순위: 부동산플래닛 → 건물 노후도·용적률
  • 2순위: 디스코 → 토지대장·등기

💡 실전 팁

  • 유동인구가 많다 = 무조건 좋은 입지가 아님. 업종 적합성이 중요. 출퇴근 시간만 사람 많은 곳에 카페 차리면 망함.
  • 매출 평균이 높은 상권이 좋은 게 아니라, 본인 업종의 매출 분포를 봐야 함.
  • 같은 동내라도 골목 단위로 매출 차이 큼. 한 단계 더 들어가서 확인 권장.
  • 아파트 → 상가 → 사무실 순으로 분석 도구의 정확성이 떨어짐. 비주거 부동산은 데이터 한계 있음.
⚠ 한계: 이 모든 데이터는 과거 기록 + 추정치입니다. 미래 예측이 아니라 현재 상태 분석에 활용. 그리고 데이터는 평균값이라 구체적 매물·점포의 실제 수익은 다를 수 있음. 임장(현장 방문) 필수.
