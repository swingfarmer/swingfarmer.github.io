📊 수익률 분석

📖 수익률 지표 설명
단순 누적 수익률 = (현재자산 − 누적원금) ÷ 누적원금. 입출금이 거의 없는 장기 계좌에서 전체 수익 규모를 직관적으로 볼 때.
CAGR (연평균 성장률) = 누적 수익률을 연 단위 복리로 쪼갠 값. 예금·부동산 등과 비교할 때 유용.
TWR (시간가중수익률) = 입출금 영향을 제거한 순수 투자 실력 지표. 벤치마크(코스피 등)와 1:1 비교 시 사용. "내 종목 픽 실력이 얼마나 좋은가?"
MWR (금액가중수익률/XIRR) = 입출금 타이밍·금액을 반영한 실제 내 지갑의 수익률. "돈을 많이 넣었을 때 수익이 났는가?" 메인 지표로 적합.
8개월 사이클 = 4월말→12월말→8월말→4월말 기준 구간별 수익률. 나만의 결산 주기.

🔄 8개월 사이클 수익률

구간시작자산종료자산입출금합수익금수익률

날짜별 총 투자자산 + 입금/출금 입력. 누적원금·수익금은 자동. 행 클릭→수정. 엔터=추가.
