📖 사용 설명

1. 관심 추가하는 법

  • ＋ 새 관심 추가 — 직접 입력. 단지 하나를 볼 땐 건물명(일부만 써도 됨), 동네 전체를 볼 땐 지역·동·면적·금액으로.
  • 📋 지금 검색조건으로 추가 — "최근 거래" 탭에서 검색해보고 마음에 드는 조건을 그대로 등록.
  • 🔖 브라우저 즐겨찾기 가져오기 — 예전 "검색조건 저장"(이 브라우저에만 있던 것)을 관심 목록으로 옮김. 지역·건물명 없는 건 건너뜀.

2. 조건 칸 뜻

  • 건물명: 이름 일부. 쉼표로 여러 개 넣으면 그중 하나라도 맞으면 포함 (예: 브라이튼, 파인루체). "아크로"처럼 짧게 쓰면 같은 지역의 아크로 단지가 다 잡힘.
  • 전용: 전용면적 ㎡ (3.3058㎡ = 1평). 금액: 만원 단위, 매매는 매매가, 전월세는 보증금 기준.
  • 지역이나 건물명 중 하나는 필수 (서울 전체 같은 조건은 너무 많아서 막아둠).

3. 카드 보는 법

  • 큰 숫자 = 가장 최근 거래 (유형·면적·층·계약일). 그 아래 3개월·3년 거래 건수.
  • 최근 6개월 평당가와 직전 6개월 대비 % — 매매가 있으면 매매, 없으면 전세 보증금 기준. 평당가 = 금액 ÷ 전용면적(평).
  • 아래 선 = 최근 3년 월별 평당가 추이. 3년 전보다 오르면 빨강, 내리면 파랑.
  • 새 N = 최근 14일 안에 알림이 간 거래 수.
  • 카드를 누르면 아래에 월별 평당가 차트 + 최근 거래 100건 표. 다시 누르면 닫힘.
  • 버튼: 🔔 알림 켜기/끄기 · ✏️ 조건 수정 · ⬆️ 순서 올리기 · 🗑️ 삭제

4. 텔레그램 알림

  • 매일 새벽 실거래 수집이 끝나면 관심 항목마다 새로 생긴 거래를 찾아 텔레그램 봇2로 보냄. 메시지: 단지·면적(평)·층·금액·평당가·계약일, 같은 건물 비슷한 평형(±3㎡) 직전 거래 대비 %.
  • 처음 등록한 날은 알림 없음 — 그때까지의 거래를 "이미 본 것"으로 저장하고, 다음 수집부터 새 거래만 보냄.
  • 국토부 신고는 계약 후 30일 이내라 알림은 계약보다 늦게 옴 (실시간 아님). 계약일이 최근 100일 안인 거래만 비교함.
  • 🔔 꺼진 항목도 새 거래는 아래 "최근 알림" 이력에는 남음 (텔레그램만 안 감).
  • 해제(취소)된 거래는 반영 안 됨.

5. 저장·데이터 범위

  • 관심 목록은 서버(DB)에 저장 → PC·폰 어디서 열어도 같은 목록. 저장은 분당 10회 제한이라 버튼을 연달아 누르면 잠깐 "저장 실패"가 뜰 수 있음 (잠시 후 다시).
  • 아파트: 강남·서초·송파·영등포 등 13곳은 20년치, 나머지 서울·분당·인천 일부 17곳은 3년치. 오피스텔: 서울 25개 구 (2023년 이후 전체). 상업업무용: 영등포구만.
  • 카드·차트 숫자는 최근 3년 거래 기준 (최대 최신 1,000건).
