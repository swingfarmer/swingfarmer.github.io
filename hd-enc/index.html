1. 리포트 4건 통합 (미래에셋 9/1 + 신한 8/31 + 메리츠 9/1 + 맥쿼리 9/3)

셀사이드 6곳 평균 TP ~180,000원. 신한 SOTP 기준 TP의 71%가 원전 옵션값 — 기존사업 가치 ~51,000원, 원전 13.5조(주당 ~121,000원). 현재가 123,300원은 원전 소폭 반영 상태.

KB/키움/미래에셋 3곳이 동시 TP 대폭 하향(-17~26%)하면서 톤 유지 = "이전 가격 과했다" 시그널.

맥쿼리 핵심: "정책 기대 → 실제 수주" 전환. DOE SPV 통한 FID 전 기자재 선발주 가능 = 기자재(두산) 먼저, EPC(현대) 다음. 두산에너빌리티 > 현대건설 선호 순위.

2. 기당 단가 교차검증 (IR + 맥쿼리 + MIT)

대형원전 AP1000: 현대 EPC 기당 3.5~5.0조원 (총사업비 50%, IR 확인)

홀텍 SMR-300: 현대 EPC 기당 1.0~1.8조원 (총사업비 60%, IR 확인)

테라파워 NOAK: 현대 EPC 기당 1.0~1.5조원

대형원전 GPM 12~15% (IR 직접 확인), OPM 5~8%. SMR FOAK "마진보다 경험 우선" → OPM 3~5%.

3. 2030 연결 OP 3시나리오

Bear 0.8~1.3조: 수주 지연 + ZATCA 반영 + 원전 매출 1.5조

Base 1.3~1.8조: 시뮬레이터 디폴트 7기. 원전 3.7조, OPM 5.5%

Bull 1.9~2.8조: 파이프라인 8건+ 본계약. 원전 7조(회사 가이던스)

회사 가이던스 3.2~4.0조는 Bull의 1.5~2배 → 현실화 확률 낮음.

4. 9~12월 촉매 캘린더

9월: 대미투자 1호 (가스발전, 두산 직접 수혜)

10월: 12차 전기본 초안 (신규 원전 +4기 가능)

4Q: 팰리세이즈 파샬 계약, 코즐로두이 FID, 체코 시공계약

12월: 전기본 최종안, WEC 기자재 발주(두산), 베트남 IGA

5. 제미나이 분석 교정

오류: 원전 OPM 9% 과대(실제 5~8%), 페르미 27 2Q 착공(실제 28~29 자금 조건부), ZATCA/CB/본드콜 리스크 누락

보완: IG 백스톱 어닝콜 확인 반영, 신한 SOTP "71% 옵션" 함의 추가

🔻 다운사이드 리스크

🔴ZATCA 사우디 세금: 잠재 0.5~1.5조. DL보다 시효 방어 어려움 (2016~19 사우디 EPC 활발). 통지 시 충당금 반영.
🔴원전 EPC 계약 지연: 파이프라인 14건 중 본계약 0건. "상반기 목표"가 반복 순연 패턴. 옵션값 71% → 미실현 시 주가 60~70k 가능.
🟠페르미 자금 미확보: 원전 4기 $32~40B 미조달. 텐서웨이브 = DC 리스, 원전 자금 아님. IG 백스톱은 확인됐으나 PF 조건부.
🟠CB 희석: 5,000억 전환가 150,607원. 전환 시 2.98% 희석.
🟠현대ENG 본드콜: 말레이·우즈벡 진행 중. 3Q 실적 노이즈 가능.
🟡코즐로두이 고정가 요구: 불가리아 정부 fixed price 요구 = LSTK 마진 리스크.
🟡SMR FOAK 공기·비용: 전 세계 완공된 SMR 0기. NuScale UAMPS 취소 전례.
