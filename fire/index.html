📘 사용 설명서

① 이 계산기의 목적

"지금 페이스로 가서 얼마 모이는지"가 아니라, "월 X만원 쓰면서 살려면 은퇴할 때 얼마가 필요한지"를 거꾸로 계산하는 도구. 목표 자산 → 현재 페이스 비교 → 부족분 → 추가로 저축해야 할 금액 까지 알려줌.

② 입력값 설명

  • 기본 정보 현재 나이·은퇴 나이·사망 나이 모두 수정 가능. 한국 평균(44/63/84세) 기본값.
  • 월 소비액 은퇴 후 매달 쓸 돈 (오늘 기준). 매년 물가만큼 자동 상승. 예: 월 300만원 → 20년 뒤 월 600만원 정도 필요 (물가 3.5% 가정).
  • 사망 시 남길 금액 오늘 기준 가치. 0이면 "다 쓰고 가기", 2억이면 "자녀에게 2억 상속" 같은 의미.
  • 연 수입액 실수령액(처분가능소득) 기준. 세금·4대보험 다 떼고 받는 금액. 한국 가구 평균 5,040만.
  • 연 지출액 현재 1년 동안 쓰는 생활비. 한국 가구 평균 3,480만(월 290만).
  • 연 저축액 (자동) = 수입 − 지출. 은퇴 전엔 이만큼 자산에 쌓이고, 은퇴 후엔 수입이 0이 되면서 위에 입력한 월 소비액 × 12만큼 자산에서 빠짐.

③ 결과 해석

  • 필요 자산 은퇴 시점에 이 금액이 있어야, 평생 월 X만원 쓰고 사망 시 N억 남길 수 있음.
  • 목표 대비 차액 현재 페이스로 도달할 자산 − 필요 자산. 마이너스면 부족, 플러스면 여유.
  • 필요 추가 저축액 부족분을 메우기 위해 매년 추가로 저축해야 할 금액. 0이거나 음수면 현재 페이스로 충분.
  • 판정 색상 🟢 충분 / 🟡 약간 부족 / 🔴 크게 부족

④ 계산 로직

  • 은퇴 전 자산 흐름: 자산 × (1+수익률) + 수입 − 지출 (현재 페이스)
  • 은퇴 후 자산 흐름: 자산 × (1+수익률) − 월소비×12 (매년 물가만큼 증가)
  • 역산: 사망 시점 자산 = 남길 금액(미래가치) 가 되도록 은퇴 시점 자산을 거꾸로 풀어냄
  • "오늘 기준" 금액들은 모두 사망 시점 미래가치로 환산해서 비교

⑤ 주의사항

  • 세금·수수료 미반영. 실수익률은 더 낮을 수 있음.
  • 수익률을 매년 일정하다고 가정. 실제로는 변동성 큼 → 보수적으로 잡는 게 안전.
  • 국민연금·퇴직연금 미반영. 노후소득 있다면 "월 소비액"에서 차감해서 입력.
  • 의료비 급증 가능성 미반영. 사망 시 남길 금액을 조금 더 잡거나, 사망 나이를 길게 잡는 방식으로 버퍼 확보 권장.
  • 큰 일회성 지출(주택구입·자녀교육·결혼자금 등) 미반영.
