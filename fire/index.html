FIRE 역산 계산기

월 소비액과 사망 시 남길 금액을 입력하면 은퇴 시점에 얼마가 필요한지 자동 역산. 기본값은 한국 평균 (은퇴 63세 / 기대수명 84세).

📘 사용 설명서

① 이 계산기의 목적

"지금 페이스로 가서 얼마 모이는지"가 아니라, "월 X만원 쓰면서 살려면 은퇴할 때 얼마가 필요한지"를 거꾸로 계산하는 도구. 목표 자산 → 현재 페이스 비교 → 부족분 → 추가로 저축해야 할 금액 까지 알려줌.

② 핵심 입력값

  • 월 소비액 오늘 기준 화폐 가치로 입력. 매년 물가만큼 자동 상승함. 예: 월 300만원 → 20년 뒤엔 월 600만원 정도 필요 (물가 3.5% 기준).
  • 사망 시 남길 금액 오늘 기준. 0이면 "다 쓰고 가기", 2억이면 "자녀에게 2억 상속" 같은 의미.
  • 사망 나이 한국 평균 기대수명 84세 기본값. 본인 가족력·건강 고려해서 더 길게 잡는 게 보수적 (오래 살 위험이 더 위험함).

③ 결과 해석

  • 필요 자산 은퇴 시점에 이 금액이 있어야, 평생 월 X만원 쓰고 사망 시 N억 남길 수 있음.
  • 목표 대비 차액 현재 저축 페이스로 도달할 자산 − 필요 자산. 마이너스면 부족, 플러스면 여유.
  • 필요 추가 저축액 부족분을 메우기 위해 매년 추가로 저축해야 할 금액. 0이거나 음수면 현재 페이스로 충분.
  • 판정 색상 🟢 충분 / 🟡 약간 부족 / 🔴 크게 부족

④ 계산 로직

  • 은퇴 후 매년: 자산 × (1+수익률) − 그해 지출 (월소비×12, 매년 물가만큼 증가)
  • 역산: 사망 시점 자산 = 남길 금액(미래가치) 이 되도록 은퇴 시점 자산을 거꾸로 풀어냄
  • "오늘 기준" 금액들은 모두 입력 받은 후 사망 시점 미래가치로 환산해서 계산

⑤ 주의사항

  • 세금·수수료 미반영. 실수익률은 더 낮을 수 있음.
  • 수익률을 매년 일정하다고 가정. 실제로는 변동성 큼 → 보수적으로 잡는 게 안전.
  • 국민연금·퇴직연금 미반영. 노후소득 있다면 "월 소비액"에서 차감해서 입력.
  • 의료비 급증 가능성 미반영. 사망 시 남길 금액을 조금 더 잡거나, 사망 나이를 길게 잡는 방식으로 버퍼 확보 권장.
