📌 저작권 및 이용 안내
본 페이지는 각 언론사가 공개적으로 제공하는 RSS 피드를 활용하여 헤드라인과 출처를 표시하는 비상업적 큐레이션 서비스입니다.
• 모든 기사의 저작권은 해당 언론사에 있으며, 본 페이지에는 기사 본문이 포함되어 있지 않습니다.
• 기사 제목 클릭 시 해당 언론사의 원본 페이지로 이동합니다.
• RSS는 GitHub Actions로 2시간마다 서버에서 수집하여 정적 JSON으로 제공합니다.
