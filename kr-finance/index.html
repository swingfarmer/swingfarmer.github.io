🔍 사용법
• 기간 선택 — 상단 탭으로 연간/분기 데이터 전환. 분기 탭은 그 분기 3개월 실적(ROE·ROA 연환산 안 함, D&A·EBITDA도 3개월치), 배당금은 연초부터 그 분기까지 누적, 배당 지표(배당률·배당성향·분리과세)와 EV/EBITDA는 연간 탭에만 나옴(최근 4분기 합 EV/EBITDA는 유사종목 찾기 페이지)
• 검색 — 종목명 또는 종목코드 입력
• 업종 필터 — 탭으로 업종별 보기
• 정렬 — 열 헤더 클릭 (한번 더 클릭하면 반전)
• 비교 — 체크박스로 2종목 이상 선택 → 하단 "비교하기" 클릭
📊 지표 설명
• OPM — 영업이익률. 본업의 수익성
• NIM — 순이익률. 세후 최종 수익성
• 외화 재무 — 두산밥캣처럼 재무제표를 달러로 내는 회사는 종목명 아래 「USD 재무」, 금액 칸 앞에 USD가 붙음(예: USD 62억 = 62억 달러). 분리과세는 회사 공시 배당성향으로 판정, EV/EBITDA는 계산 안 함
• 순이익 / 지배순이익 — 연결 당기순이익(자회사 소수주주 몫 포함) / 그중 지배기업 주주 몫. 지주사는 차이가 큼. 연결이 없는 회사는 지배순이익이 비고 순이익과 같음
• ROE — 자기자본이익률. 주주 돈의 효율
• ROA — 총자산이익률
• 부채비율 — 부채÷자본. 금융업은 1000%↑ 정상
• YoY — 전년 동기 대비 증감률. "적전"=흑자→적자
• EBITDA — 영업이익+감가상각비. 현금 창출력
• D&A — 감가상각비+무형자산상각비. DART 현금흐름표에 따로 적은 회사만 나옴 — 삼성전자·SK하이닉스처럼 주석에만 두는 회사는 「-」(그래서 EBITDA·EV/EBITDA도 「-」). 현금흐름표는 연초부터 누적이라 분기 탭은 직전 분기 누적을 빼서 3개월치로 맞춤
• EV/EBITDA — 기업가치÷EBITDA. 낮을수록 저평가 (7 이하 관심)
• PER — 주가÷EPS. 낮을수록 저평가 (업종별 상대 비교)
• PBR — 주가÷BPS. 1 미만이면 자산 대비 저평가
• 52주고/저 — 최근 1년간 최고·최저가
• 배당률 — 주당배당 ÷ 현재가. 5%↑ · 3~5%
• 배당성향 — 현금배당총액 ÷ 지배주주 순이익 (분리과세 판정과 같은 기준). 외화 재무(두산밥캣)·자료 없는 종목은 회사 공시 배당성향, 그것도 없으면 DPS÷EPS(EPS = 현재가÷PER)
• 조정성향 — (현금배당총액 + 자사주소각 추정액) ÷ 지배순이익. 참고용 — 분리과세 판정에는 안 씀(법은 현금배당만)
자사주 소각액 = DART 소각 수량 × 현재가 (추정치)
• 분리과세 — 고배당기업 분리과세(14~30%) 요건 판정 (현금배당 배당성향 기준)
배당성향 = 현금배당총액 ÷ 지배순이익(연결, 연결 없으면 별도) · 공통: 전년보다 현금배당총액이 줄면 대상 아님
조건1: 배당성향 ≥ 40%
조건2: 배당성향 ≥ 25% AND 전년 대비 현금배당 10%↑
적자특례: 지배순이익 0 이하면 배당성향 25%로 보고 조건2 판정, 부채비율 200% 초과면 0%로 봄(대상 아님)
리츠·인프라 투융자회사는 대상 아님 · 칸에 마우스를 올리면 판정 근거(배당성향·전년 대비)가 나옴
공식 해당 여부는 회사가 정기주총 뒤 「기업가치 제고계획」 공시로 밝힘 — 여기 판정은 DART 숫자로 미리 본 추정
⚠️ 자사주 소각액은 소각수량×현재가 추정. 법적 기준(취득가액)과 차이 있을 수 있음
🎨 색상
• ■ 초록 — 양호 (이익률 10%↑, 증가)
• ■ 빨강 — 주의 (적자, 감소, 적전)
• ■ 노랑 — 경고 (부채비율 100~200%)
※ 재무: OpenDART · 분기별 자동 업데이트 (4/5, 5/20, 8/20, 11/20)
※ 주가·PER·PBR: KIS Open API · 평일 장 마감 후 자동 업데이트
