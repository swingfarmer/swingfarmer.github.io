📖 사용 가이드

배열 상태
· 정배열 — 종가 ≥ MA5 ≥ MA10 ≥ MA20 ≥ MA50. 모든 이평선이 순서대로 정렬된 강한 상승 추세.
· 역배열 — 종가 ≤ MA5 ≤ MA10 ≤ MA20 ≤ MA50. 모든 이평선이 반대로 정렬된 하락 추세.
· 준정배열 — 종가가 MA5·10·20 위에 있지만 이평선끼리 순서가 완벽하지 않음. 상승 전환 초기.
· 준역배열 — 종가가 MA5·10·20 아래에 있지만 이평선끼리 역배열 순서가 안 맞음. 하락 전환 초기.
· 혼조 — 위 네 가지에 해당하지 않는 상태. 방향성 불분명.

MA 강도순
· MA5·10·20·50 이격도(%)를 합산한 점수. 높을수록 이평선 대비 종가가 위에 있음 = 강한 업종.
· 정배열 필터 + MA 강도순 정렬 → 정배열 중에서도 가장 강한 업종 찾기.

KOSPI 대비 상대강도
· 해당 업종 등락률 − KOSPI 등락률 (%p). 양수면 시장보다 강함, 음수면 약함.
· 시장이 빠질 때 버티는 업종 = 다음 반등 시 주도 업종 후보.

RSI (14)
· 70 이상: 과매수 (단기 과열). 30 이하: 과매도 (반등 가능성).
· 과매도 업종 내 대장주가 반등 시 가장 빠르게 움직이는 경향.

활용 팁
· 업종별 필터 + 정배열만 + MA 강도순 → 현재 가장 강한 업종 섹터 파악
· 상대강도 ↓ 정렬 → KOSPI 대비 초과수익 업종 (로테이션 선행 지표)
· RSI ↑ 정렬 + 역배열 필터 → 과매도 반등 후보 업종
· 카드 클릭 → 차트에서 이평선 배열 흐름 시각적 확인
