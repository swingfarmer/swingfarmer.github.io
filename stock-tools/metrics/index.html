📡 데이터 조회 (네이버 증권 / 다트 / 컴퍼니가이드)

  • 한 종목 빠른 조회: 네이버 증권 → 종목 검색 → "투자정보" 탭에서 EPS/BPS/PER/PBR/ROE 다 보임
  • 재무제표 원본: 전자공시 DART → 종목 검색 → 사업보고서/분기보고서
  • 상세 재무 분석: 컴퍼니가이드 → 종목 검색 (재무비율, 산업비교)

📘 지표 설명

① 가치평가 지표 (싸냐/비싸냐)

  • PER Price/Earnings Ratio. 주가가 EPS의 몇 배인가. 낮을수록 저평가. 한국 평균 10~15배. 성장주는 높고 가치주는 낮음.
  • PBR Price/Book-value Ratio. 주가가 BPS의 몇 배인가. 1배 이하면 청산가치 미만. 금융·철강 같은 자산 많은 업종은 낮고, IT/플랫폼은 높음.
  • PSR Price/Sales Ratio. 시총이 매출의 몇 배인가. 적자 기업 평가에 유용.

② 수익성 지표 (얼마나 잘 버나)

  • ROE Return On Equity. 자기자본 1원으로 1년에 얼마 버나. 15%+ 우수, 10% 적정, 5% 미만 부진. 워런 버핏 최애 지표.
  • ROA Return On Assets. 총자산 1원으로 1년에 얼마 버나. 부채 많은 회사는 ROE는 좋아도 ROA는 낮을 수 있음.
  • 순이익률 매출의 몇 %가 최종 순이익으로 남나. 업종별 큰 차이.
  • 자기자본비율 총자산 중 자기자본 비율. 50%+ 안정, 30% 미만 위험.

③ 배당 지표

  • 시가배당률 현 주가에서 매수해서 1년 들고 있으면 받는 배당수익률. 한국 평균 2~3%, 4% 이상이면 고배당주.
  • 배당성향 순이익 중 몇 %를 배당으로 나눠주나. 30~50% 적정. 너무 높으면 (80%+) 지속가능성 의문, 너무 낮으면 (10% 미만) 주주환원 부족.

④ 색상 의미

  • 🟢 녹색 = 우수 (좋은 신호)
  • 🟡 황색 = 보통 (중립)
  • 🔴 빨강 = 주의 (부정적 신호)
