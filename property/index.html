📖 이 분석기의 목적

상가 매물의 진짜 수익률을 계산합니다. 광고 수익률(예: 4.75%)이 아니라, 취득세·중개료·재산세·관리비·임대소득세·대출이자까지 다 차감한 후 손에 들어오는 실제 수익률을 계산합니다.

⚡ 빠른 사용법 (4단계)

  • 1단계: 위의 [📥 매물 정보 입력]에서 매매가·보증금·월세 입력
  • 2단계: [④ 광고 표시 수익률]에 중개사가 광고에 적은 수익률 입력 (선택, 부풀린 광고 검증용)
  • 3단계: [📊 기본 분석] 탭에서 7가지 수익률 확인. ⑤번이 "진짜 수익률"에 가장 가까움
  • 4단계: [📈 가격 시나리오]·[🏢 법인 비교] 탭에서 추가 분석

🔢 7가지 수익률 — 무엇이 다른가

  • ① 광고 표시 수익률: 중개사가 알려준 광고용 값. 사용자가 직접 입력. 비교용으로 자동계산값(연임대료/(매매가-보증금))과 차이도 표시. 부풀려진 광고를 잡아내는 용도.
  • ② Gross: 연임대료 ÷ 매매가. 단순 비교용.
  • ③ Cap Rate (NOI/매매가): ⭐ 부동산 평가 국제 표준. 다른 매물과 비교할 때 이 숫자.
  • ④ NOI/실투자금 (대출X): 보증금·부대비용 반영.
  • ⑤ 세후/실투자금 (대출X): ⭐⭐ 가장 현실적. 현금 들고 살 때 진짜 수익률.
  • ⑥ 세전/실투자금 (대출O): Cash-on-Cash. 대출 활용 시 자기자본 세전 수익률.
  • ⑦ 세후/실투자금 (대출O): ⭐⭐⭐ 최종 수익률. 마이너스면 역레버리지 상태.

⚖️ 핵심 판단 기준

  • Cap Rate(③) > 대출금리 → 대출 받을수록 수익률 ↑ (정상 레버리지)
  • Cap Rate(③) < 대출금리 → 대출 받을수록 수익률 ↓ (역레버리지) — 현재 시장 다수가 이 상태
  • ⑤번이 정기예금 금리보다 낮으면, 부동산 위험을 떠안을 이유 약함
  • 이 분석기는 보유 중 현금흐름만 계산. 매도 시 양도차익/양도세는 별도 검토

🛠️ 가정값 조정 가이드 ([⚙️ 가정값 설정] 탭)

  • 임대소득세율: 본인 종합소득 기준 한계세율(지방세 포함). 6.6%~49.5%.
  • LTV/대출금리: 실제 대출 조건. 상가 통상 50~60%, 5~6%대.
  • 공실률: 보수적 5%. 안정적 입지 3%, 외곽 10%.
  • 재산세율: 매매가 대비 0.25% 보수적. 실제는 공시지가 기준이라 더 낮을 수 있음.
  • 건물분 VAT: 일반과세 사업자 등록 시 환급 가능 → 0%.

🏢 개인 vs 법인 매수 — 어떻게 다른가

  • 법인 장점: 이자·감가상각이 비용처리 → 세금 감소. 법인세율(9.9~24%)이 한계세율보다 낮을 수 있음.
  • 법인 단점: 과밀억제권역 + 설립 5년 이내면 취득세 중과(+4.8%). 개인 인출 시 배당세(15.4% 또는 종합과세).
  • 유보 vs 인출: 재투자 목적이면 법인 유보 → 배당세 0. 생활비로 쓰려면 인출 → 한계세율과 비교.
⚠ 한계와 주의사항
• 1년 정태 분석 (DCF/IRR 아님). 임대료 인상 미반영.
• 재건축·재개발 등 자본차익 시나리오 미반영.
• 임대소득세 단순화 (종합과세 vs 분리과세, 간주임대료, 사업자등록 여부에 따라 실제 다름).
• 양도소득세 미반영. 5년 이하 단기보유 시 양도세 부담 큼.
• 공시지가/재산세 실제 부과액은 시청에 직접 조회 권장.
