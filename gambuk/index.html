의견서 4대 전략 요약

전략 1 — 비교표준지 대비 우세 + 주거지역 단가 현실화

표준지(202-3)는 100% 개발제한구역·완경사. 대상토지는 1종주거 포함 + 평탄화 완료. 인접 205번지 1종주거 공시지가 2,202,000원/㎡ 반영 요구. 소형 프리미엄(25.6 중개거래 평당 529만, 26.3 직거래 평당 619만) 제시.

전략 2 — 222-2 선례 역이용: 맹지 감점 배제 + 기타요인 1.76배 하한선

222-2번지(2024타경3789) 감평서상 맹지·부정형·완경사인데도 기타요인 1.76배 적용. 대상토지는 소로2류 접면으로 맹지 아님 → 개별요인 감점 없이 1.76배를 최저 하한선으로 적용 요구.

전략 3 — 감평서 내 단가 후려치기 배척

감평사가 고가 사례A(842,459원/㎡) 배제하고 저가 사례B(605,545원/㎡)만 선택. 거래사례기준법 631,000원 > 공시지가기준법 583,000원인데 낮은 쪽 채택. 자의적 취사선택 배척.

전략 4 — 교산신도시 교통호재 반영 + 헐값 사례 거부

222-2 평가 근거 사례는 2022.1월(교통호재 미반영). 25~26년 송파하남선 승인(총 1.8조) + 동남로 2028 조기완공 + 감북동 지상화 등 호재. 대면적 도매가(128만원/평 등) 편입 거부.

핵심 관계 룰

A ↔ BCD (직계존비속) — 동일세대 시 중복공급 불가. A 세대에 BCD 합가하면 2채 → 1채.

B ↔ C ↔ D (형제) — 주민등록 분리되면 서로 주택 수 무관.

협의양도인 주택 — 교산 안내문 기준 요약

대상자

공람공고일 이전부터 사업지구 내 400㎡ 이상 토지 소유(공유지분 포함)하고, 토지 전부를 협의양도한 자

항목내용
공급기준1세대 1주택
공급규모전용 85㎡ 이하
공급가격일반 분양가격 (할인 없음)
공급방법특별공급 (경쟁 시 추첨)
무주택 요건세대주 + 세대원 전원, 입주자모집공고일~입주 시

BCD 합산: 165+165+165 = 495㎡ ≥ 400㎡ → 통과

세대 구성 타임라인

기준일(공람공고일) 전
A 세대: A 단독 (or +배우자만)
BCD 세대: B+C+D 합가 완료 → 495㎡ 확보
기준일 ~ 보상협의
세대 유지. A 단독 신청, BCD 합의서+대표자 C 지정.
입주자모집공고일 전
C 세대분리 (C 단독 or C+B). D 별도 세대.
A 기존 주택 매도 → 무주택 전환.
입주자모집공고일
A: 무주택 → 협양주택 1채
C: 무주택 + 세대원 전원 무주택 → 협양주택 1채
결과: 가족 합계 2채

절대 금지사항

① A 세대에 BCD 합가 금지 — 전 기간. 중복공급 → 2채→1채.

② A 분양권 매수 금지 — 2018.12.11부터 분양권 = 유주택.

③ 입주모집공고일 시점 C 세대에 D 합가 금지 — D 유주택 → C 자격 탈락.

④ B 주택 매수 금지 — C 대표자 세대원이 되면 C 자격 동반 소멸.

LH 확인 필요사항

교산 안내문 기준 적용. 감북 사업 시행 전 LH 서면 질의 권장.

  • 중복공급 "동일세대" 판정 시점
  • 협의양도인 주택 대표자 사후 변경 가능 여부
  • 감북동 공람공고일 구체적 일정
  • 감북 협의양도인 주택 공급 물량 및 규모
  • B가 공유자이면서 A 세대원인 경우 중복공급 해당 여부
  • 토지 990㎡ 중 A 단독(495)과 BCD 공유(495) 등기 분할 필요 여부

자금 흐름 시뮬레이션 (Base 기준)

보상금 ~9억 수령 → 특별공급 분양가(할인 없음) 예상 9~10억 → 보상금으로 커버 or 소폭 부족.
이주자택지(할인) 대상 아님 — 주거용 건물 없는 농지이므로 일반 분양가 적용.

세법(적정이율, 비과세 요건)은 매년 변동. 실행 직전 세무사 확인 필수.

실행 체크리스트

기준일 전

  • B를 A 세대에서 전출 → BCD 세대로 전입
  • A 세대: A 단독 확인
  • BCD 세대: B+C+D 동일 주민등록표 확인
  • 등기부등본: A 단독 495㎡ / BCD 공유 495㎡ 정리

보상협의 시

  • A: 단독 신청서 제출
  • BCD: 합의서 + 인감증명서 + 대표자 C 지정

입주자모집공고일 전

  • C 세대분리: C 단독세대 (or C+B)
  • A 기존 주택 매도 → 무주택
  • A 분양권 미매수 재확인
  • B 주택 미매수 재확인

입주자모집공고일

  • A: 무주택 확인 → 1채 신청
  • C: 무주택 + 세대원 전원 무주택 → 1채 신청
  • A 세대에 BCD 아무도 없는지 최종 확인

이 문서는 투자 조언이 아닌 개인 분석 정리 목적이며, 법적 효력 없음. 감정평가 산식 역산은 추정치이며 실제 보상액과 다를 수 있음.
협의양도인 주택 전략은 하남교산 이주대책 안내문(2025.04, LH) 기준 적용. 감북 사업 시행 시 별도 규정 확인 필수.
세법·주택공급규칙은 수시 변동 — 실행 직전 전문가 확인 권장.
