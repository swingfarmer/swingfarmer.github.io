미국채 매수 가이드 — 개인(저쿠폰) vs 법인, 증권사 선택과 호구 방지

(2026.11 작성 / 제미나이·블로그 자료 검증 후 보완 / 계산기: us-treasury-guide.html)

한 줄 결론

- 개인 = 저쿠폰 현물: 맞음. 그대로 진행 (3~5년 중기 저쿠폰, KB 환전 → 삼성 매수 루트 유지)

- 법인 = 고쿠폰: 반만 맞음. 법인은 쿠폰 고르기 전에 "채권을 직접(현물) 살지, 채권 ETF를 살지"부터 정해야 함.

11% 법인이면 만기 보유 기준 현물 국채가 ETF보다 같거나 유리 (미국 원천징수 0% vs ETF 15%)

→ 제미나이의 "법인은 ETF가 정답"은 11% 법인 기준으론 틀림

- 증권사는 "어디가 싸다"가 아니라 "같은 종목 단가를 YTM으로 바꿔 비교"가 정답.

[용어 먼저]

"현물"과 "ETF"

- 현물 = 채권 자체를 사는 것. 증권사 '해외채권' 메뉴에서 사면 저쿠폰이든 고쿠폰이든 다 현물

- ETF = 채권 수백 개 담은 펀드를 주식처럼 사는 것 (SGOV, TLT 등)

- 결정 순서: ① 현물로 살지 ETF로 살지 → ② 현물이면 저쿠폰인지 고쿠폰인지

- "쿠폰보다 현물 vs ETF가 먼저" = ①에서 생기는 수익률 차이가 ②보다 크다는 뜻

1. 개인 = 저쿠폰 현물 (검증: 맞음)

- 채권 매매차익·환차익 비과세, 표면이자만 15.4%(금종세 합산)

- 예: 잔존 3.5년 0.625% 쿠폰, YTM 3.6%면 수익 중 약 80%가 비과세 (계산기 기본값)

- 리스크

· 쿠폰 낮을수록 듀레이션 길어짐 → 장기 저쿠폰(2040~50년물)은 금리 리스크 큼. 제미나이 예시(2050년 1.25%)는 내 3~5년 선호와 다름

· 환차손 헤지 없음 → 손익분기 환율 확인 (계산기 기본값 기준 약 1,22x원)

· 해외상장 채권 ETF(TLT 등)는 개인이면 매매차익 22% → 개인은 현물이 맞음

- 미국 상속세: 개인의 미국 국채 현물은 대상 아님, 미국 상장 ETF·주식은 6만달러 초과분 대상

⚠ 제 이해 수준, 전문가 확인 권장

2. 법인 — 쿠폰 고르기 전에 "현물로 살지 ETF로 살지"부터

[현물 국채]

- 미국: 외국인 국채 이자 원천징수 0% (portfolio interest 비과세)

- 한국: 증권사가 이자 지급 시 15.4% 원천징수 → 법인세 신고 때 기납부세액 공제

- 비용: 매수 시 단가에 마진 1회 (만기 보유면 연 환산 몇 bp~수십 bp)

[미국 채권 ETF (SGOV·TLT)]

- 분배금 미국 15% 원천징수 (국내 증권사 대부분, ⚠ 내 계좌 거래내역으로 확인)

- 11% 법인: 10%만 공제, 5%p 10년 이월 → 실효 약 16% + 총보수

- 22% 법인: 전액 공제 → 손해 없음

- 장점: 호가 촘촘, 수수료 0.07~0.25%, 중도 매매 쉬움

[판정]

- 11% 법인 + 만기 보유 → 현물 (계산기에서 고쿠폰 10년물 예시: 현물 세후 4.05% vs ETF 3.19%)

- 22% 법인 → 비슷. 중도 매매 계획 있으면 ETF

- 금리 베팅·중도 매매 → ETF

[쿠폰 선택]

- 현금흐름 필요(운영비) → 고쿠폰

- 쌓아둘 돈 → 저쿠폰이 할인분 과세를 만기로 미루는 이연효과. 단 3~5년물은 효과 몇 bp 수준으로 작음

⚠ 해외 국채 할인 매입분 과세 시점은 세무사 확인

- 소규모법인(B) 판정 위험이 있으면 고쿠폰 이자는 판정 분자 증가 → [[법인 투자 전략]] 노트 참고

⚠ 저쿠폰 할인분이 이자로 분류될지 처분이익으로 분류될지 세무사 확인

[외화 평가]

(제미나이 "외화환산 폭탄"은 과장)

- 일반 법인은 기본이 취득일 환율(평가 안 함, 법인세법 시행령 §76② 1호)

- 사업연도 종료일 환율 평가를 "신고한" 법인만 미실현 환차익·환차손 매년 반영

- 트리플통상 평가방법 신고 여부 세무사에게 확인

3. 증권사 선택 — 수수료 방식, 환율, 개인/법인

[증권사가 수수료 떼는 방식 3가지]

① 단가에 포함: 별도 수수료 없이 매수 단가에 마진이 녹아 있음 (삼성·키움·메리츠 등이 이렇게 안내)

② 거래금액의 %: 매수 금액에 한 번 부과 (한투: 잔존 1년 미만 0.1% / 2년 미만 0.2% / 그 이상 0.3%, 소액시장 0.6% · 신한 0.19%) — 2025.6 자료

③ 연 %×잔존연수: 연 환산 요율에 남은 기간을 곱해 한 번에 부과 (미래에셋 온라인 연 0.15% 수준) — 장기채일수록 커짐, 2026 블로그 자료

→ ②③은 단가가 싸 보여도 수수료를 더하면 비쌀 수 있음. 반드시 수수료 포함해서 비교

[환율이 적용되는 방식]

실제 환율 = 매매기준율 ± 기본 스프레드 × (1 − 우대율)

예) 매매기준율 1,400원, 기본 스프레드 1%(14원)

우대 0% → 살 때 1,414원 / 95% → 1,400.7원 / 100% → 1,400원

1억 환전 시 우대 0%와 95% 차이 약 95만원

- 야간엔 우대율이 낮아지거나 임시 환율(가환율)을 쓰는 곳이 있음 → 평일 주간 환전

- 만기에 원화로 되돌리면 환전비용이 한 번 더 듦 (달러로 계속 두면 없음)

[증권사별 정리]

(확인 수준 표시 — 수수료·이벤트는 수시로 바뀜)

[추천 방식]

- 개인: 삼성·메리츠·키움 중 2~3곳 같은 종목 단가 비교 + 한투·미래·신한은 수수료 더해서 비교. 환전은 우대 100%인 곳에서 하고 외화로 옮겨도 됨

- 법인: 비대면 이벤트 안 되니 대형사 2곳(예: 삼성 + 한투 또는 미래) 계좌 → 지점에 환전 우대율·채권 단가 요청 → 견적 경쟁

- 표는 출발점일 뿐. 최종 판단은 실제 단가로

[내 루트]

- 개인: KB증권 환전(100% 우대) → 삼성증권 외화 가상계좌 → 삼성에서 매수 — 유지

· 매수 전 메리츠·키움 단가도 띄워 비교 (계산기 '증권사 견적 비교')

· KB 우대 조건 만료일, 외화 이체 수수료 주기적으로 확인

- 법인: 트리플통상 계좌 개설 시 지점에 ① 환전 우대율 ② 해외주식 수수료율 ③ 채권 단가 협의 미리 요청

· "지점 협의로 마진 20~40bp" 주장은 근거 확인 못함 ⚠ → 실제 견적으로 판단

4. 호구 방지 체크리스트

1) 단가 → YTM 환산해서 시장 금리와 비교. 차이(bp) = 증권사 마진

시장 금리 확인: investing.com / CNBC / 미 재무부 일별 금리

⚠ 시장 금리는 지표물 기준이라 오래된 저쿠폰물은 몇 bp 다를 수 있음

2) 앱의 "세전환산수익률"(비과세분 부풀림), "단리 환산 수익률"(장기 누적 ÷ 연수) 무시. 세전 YTM(복리)으로만 비교

3) 같은 만기·같은 쿠폰 2~3곳 견적

4) 중도 매도 가능성 있으면 매수 전 매도 호가 확인

5) 환전은 평일 주간. 야간은 우대율 낮아지는 곳 많음

6) 경과이자는 손해 아님 (다음 이자일에 회수)

7) 법인: 원천징수 15.4% 기납부세액 공제 챙기기, 외화 평가방법 확인

8) 삼성 이자 세금 처리: 이자 달러 입금 → 세금은 원화 예수금에서 차감, 원화 없으면 익영업일 달러 자동 환전

계산기 사용법 (us-treasury-guide.html)

1. 증권사 앱에서 채권 띄우기 — 종목명 "T 0.625 05/15/30" = 쿠폰 0.625%, 만기 2030.5.15

2. 잔존 기간·표면금리·매수 단가(액면 100 기준, 결제금액 아님) 입력

3. 같은 만기 시장 금리 입력 — investing.com "미국 3년 국채" 등, 또는 미 재무부 Daily Treasury Par Yield Curve. 3.5년이면 3년·5년 사이 값

4. '숨은 마진' 확인 — 10~30bp 무난, 50bp 넘으면 다른 곳 견적 필수 (⚠ 기준선은 경험칙)

5. 여러 증권사 견적은 '증권사 견적 비교'에 — 단가, 수수료 방식(단가 포함 / 거래금액 % / 연%×잔존), 수수료율, 환전 우대율 입력 → 수수료·환전 합친 최종 실질 수익률 순위

6. 법인이면 법인세율 선택 + ETF 분배율 넣어서 '현물 vs ETF' 카드 확인

- 1bp = 0.01%p. 마진 20bp, 1억, 잔존 3.5년이면 약 68만원이 매수 시점에 증권사 몫

5. 받은 자료 검증 결과

[제미나이]

맞음: 장외채권은 마진이 단가에 녹아 있음, YTM 비교가 핵심, 개인 저쿠폰 논리, 저쿠폰 듀레이션·환율 리스크,

법인 비대면 이벤트 미적용, 법인 원천징수 기납부 공제, 경과이자 설명, 단리 수익률 착시

틀림/과장:

- "법인은 현물보다 ETF가 유리" → 11% 법인은 ETF 15% 원천징수 손해 누락. 만기 보유면 현물이 같거나 유리

- "법인=고쿠폰이 완벽한 정답" → 법인은 쿠폰 무관하게 전부 과세. 목적(현금흐름 vs 적립)으로 고를 문제

- "외화환산이익 과세 폭탄" → 일반 법인 기본은 평가 안 함. 신고한 법인만 해당

- 시뮬레이터: 개인 과세이자를 "쿠폰×1.4"로 임의 계산, 개인 고쿠폰 35% 일괄 가정, 단가·YTM 계산 없음 → 새 계산기로 대체

- 증권사별 우열·수수료 수치(토스 1.5%, 법인 20~40bp, 중도매도 1.5~3%)는 근거 미확인

[블로그 - 증권사 수수료 비교(2025.6)]

- "매매차익은 양도소득세 22%"는 틀림 → 해외채권 직접투자 매매차익은 개인 비과세 (22%는 해외상장 ETF 얘기)

- 이자를 "배당소득세"라고 쓴 것도 틀림 → 이자소득

- 삼성 수수료 상한(잔존기간별 1~3.3% 이하)은 "상한"이고 실제는 단가에 녹아 있음

[블로그 - 장기채 직접투자(2026.7)]

- 세금 구조 표 정확 (직접투자 비과세 / 해외상장 ETF 22% / 국내상장 ETF 15.4%)

[블로그 - 미국주식 수수료(2026.8)]

- 이벤트 대부분 종료됐다는 내용 → 다른 자료와 충돌. 증권사 이벤트는 앱에서 직접 확인
