2. Bull / Base / Bear 시나리오

Bull Case (다올: 27E OP 7,765억 → TP 46,000원)

  • 원화 강세 지속 → 원재료 수입 원가 대폭 하락
  • 당진 전기료 인하 800억 확정 반영
  • 반도체/DC 착공 → H형강 물량 폭발
  • 밸류업 발표 + 자사주 소각
  • "다 맞으면" 27E PER 4~5배, 주가 2배

Base Case (중앙값: 27E OP ~5,400억 → TP 40,000~43,000원)

  • 4Q 판매량 정상화(420만톤+), 스프레드 확대
  • 포스코 광양 2고로 수리 반사이익으로 열연가 지지
  • 전기료 인하 일부 반영, 밸류업은 27H1 발표
  • 주가 25,000→35,000~40,000원 (+35~55%)
  • 단, 도달 시점이 27년 하반기 이후일 가능성 높음

Bear Case (BNK: 27E OP 3,031억 → 하방 시나리오)

  • 중국 철강 수출 재증가 + 제3국 우회 수입 확대
  • 열연 AD 효과 희석, 유통가 90만원선 붕괴
  • 건설 착공 회복 지연 (금리 고착화)
  • 탄소배출권 비용 추가 부담 + 밸류업 추가 지연
  • 27E OP가 올해(2,700억)와 큰 차이 없음 → 횡보 22,000~25,000원

3. 솔직한 평가

좋은 점

  • PBR 0.17배 + 모비스 지분 = 하방 극히 제한. 여기서 -20% 더 빠지려면 철강업 자체가 구조적으로 망해야 함
  • 12사 전원 BUY. 최저 TP 37,000원도 현재가 대비 +43%
  • 자동차/조선 캡티브(고정 수요처)로 동국제강보다 이익 안정성 높음

나쁜 점

  • 12사 전원 BUY인데 주가는 안 올라 → 시장이 셀사이드를 안 믿고 있다는 뜻
  • 27E OP 격차 3,031~7,765억으로 2.6배 — 컨센서스 자체가 무의미에 가까움
  • 촉매가 전부 "내년" → 밸류업(27H1), 전기료(27년), HPLS(29년). 지금 살 이유가 "싸니까"밖에 없음
  • 배당 1.9%로는 기다리는 동안 보상 빈약
판단: 모비스 지분이라는 청산가치 하한선이 있어서 "영구적 밸류 트랩"은 아님. 다만 시간의 기회비용이 문제. 6개월~1년 묶일 각오가 없으면 지금 진입은 비효율적.
